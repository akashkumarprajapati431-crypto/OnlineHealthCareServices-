HealthConnect - Online Healthcare Services Website

FILES
- index.html: website structure and content
- style.css: design and responsive layout
- script.js: mobile navigation, copyright year, and demo contact form

HOW TO RUN
1. Extract this ZIP file.
2. Open the healthcare-website folder.
3. Double-click index.html to open it in a web browser.
4. Internet access is needed for the remote images and Google Fonts.

IMPORTANT
This is a front-end demo only. Login, registration, appointments, prescriptions, and sending contact messages are not connected to a backend. Do not enter real medical or sensitive personal information.
